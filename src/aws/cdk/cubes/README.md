# Datacubes Batch CDK App

This CDK app (`app.py`, stack `DatacubesBatchStack`) deploys the AWS Batch compute
environments, job queues, and job definitions used by the ITS_LIVE virtual and
deep-copy cube pipelines.

## Setup

```bash
conda env create -f cubes.yml
conda activate its-live-cdk
npm install   # first time only, if node_modules/package-lock.json don't exist yet
npm ci        # afterward, to reproduce that exact install
```

## Deploy

```bash
npx --no-install cdk synth    # see the generated CloudFormation template
npx --no-install cdk diff     # compare against what's currently deployed
npx --no-install cdk deploy   # apply the changes
```

`--no-install` forces npx to use the pinned CDK CLI already installed by `npm ci`
instead of fetching/installing another version.

## Cleanup

`./clean_deploy_artifacts.sh` removes stale `cdk.out/` and any leftover deploy-session
logs from past runs -- everything it removes is regenerated by the next `cdk synth`/
`cdk deploy`.
